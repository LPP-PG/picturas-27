As diretrizes da Fase 1 pedem que os requisitos comuns a várias funcionalidades sejam especificados uma só vez, com os vários casos de uso como origem. Este ficheiro reúne os requisitos sobre os pedidos de processamento de vídeo (estado, progresso, cancelamento, quota, pedidos em simultâneo, eliminação e notificação) que estavam repetidos nos três casos de uso. Os requisitos substituídos foram retirados de cada caso de uso e os seus IDs não são reutilizados (tabela de correspondência no fim).

As regras de negócio transversais (RNG-nn) referidas na origem estão no capítulo 3.4 do relatório. Os elementos locais são qualificados pelo caso de uso (por exemplo, UC-VID-001: FA6).
